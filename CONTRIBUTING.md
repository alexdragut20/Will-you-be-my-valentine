# Contributing Guide

Thanks for contributing.

## Development

1. Start local server:

```bash
python3 -m http.server 8765
```

2. Open `http://localhost:8765`.
3. Edit `index.html`, `styles.css`, `script.js`.

## Pull Request Checklist

- Keep the envelope and modal interactions working.
- Preserve mobile behavior for the evasive `No` button.
- Keep animations smooth and performant.
- Test in at least one desktop and one mobile browser.
- Update `README.md` if behavior or setup changes.
